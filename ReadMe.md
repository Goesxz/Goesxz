## 🚀 Featured Projects

### 1. Finances — Personal Finance Dashboard

A personal finance management application focused on organizing transactions, budgets, and financial insights.

**Built with:** React 19, Vite, Recharts, JavaScript.

- Transaction and budget management.
- Local data persistence using localStorage.
- Financial charts and reports.
- JSON backup and CSV export.
- Unit tests with Vitest.

[🌐 Live Demo](https://dashboard-eight-flax-62.vercel.app/) · [📂 Repository](https://github.com/Goesxz/DASHBOARD)

---

### 2. JC Beauty — Appointment & Business Management System

A full-stack application designed to connect the customer booking experience with the operational management of a beauty studio.

**Built with:** React, TypeScript, Node.js, Express, Prisma, SQLite.

- Online appointment scheduling.
- Service and customer management.
- Administrative dashboard.
- JWT-based authentication.
- Financial management and reports.

[🌐 Live Demo](https://jc-beauty-zeta.vercel.app/) · [📂 Repository](https://github.com/Goesxz/JC-Beauty)

---

### 3. CONF LEGACY — Conference Website

A conference website designed to showcase the event, engage visitors, and encourage participation through an online registration form.

**Built with:** React 19, TypeScript, Vite, Framer Motion, Google Forms.

- Event presentation and information.
- Interactive and animated user interface.
- Registration interest collection through Google Forms.
- Responsive experience.

[🌐 Live Demo](https://conf-lgcy.vercel.app/) · [📂 Repository](https://github.com/Goesxz/CONF-LGCY)
